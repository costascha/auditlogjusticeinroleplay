# Ρύθμιση Supabase και Tickets

Η εφαρμογή χρησιμοποιεί το Supabase για σύνδεση χρηστών και αποθήκευση αιτημάτων.

1. Δημιούργησε ένα project στο Supabase και άνοιξε το **SQL Editor**.
2. Εκτέλεσε το περιεχόμενο του [`supabase/schema.sql`](./supabase/schema.sql).
3. Από το **Authentication → Users**, δημιούργησε λογαριασμούς για τους χρήστες.
   Το προφίλ κάθε λογαριασμού δημιουργείται αυτόματα.
4. Για να δώσεις δικαιώματα διαχειριστή, βρες το UUID του λογαριασμού και εκτέλεσε:

   ```sql
   update public.profiles
   set is_admin = true
   where id = 'AUTH_USER_UUID';
   ```

5. Αντέγραψε το `config.example.js` σε `config.js` και συμπλήρωσε το Project URL
   και το **anon/public key** από τα API settings του Supabase.
   Μην τοποθετήσεις ποτέ το `service_role` key στον browser.
   Στο **Authentication → URL Configuration**, πρόσθεσε το origin της εφαρμογής
   στα επιτρεπόμενα redirect URLs για την επαναφορά κωδικού.
6. Σέρβιρε τον φάκελο μέσω HTTP (όχι με `file://`), π.χ.
   `python3 -m http.server 8000`, και άνοιξε το `http://localhost:8000`.
   Η φόρτωση της βιβλιοθήκης Supabase απαιτεί σύνδεση στο διαδίκτυο.

Τα tickets λαμβάνουν αυτόματα μοναδικό αριθμό της μορφής
`1-1234567890123456`. Οι χρήστες βλέπουν μόνο τα δικά τους αιτήματα· οι
διαχειριστές βλέπουν όλα τα αιτήματα και μπορούν να αλλάξουν την κατάστασή τους.
Η πρόσβαση εφαρμόζεται και στη βάση μέσω Row Level Security (RLS).
